# 输入框按钮：需求

在现有「用 VSCode 打开」插件上做增量：把斜杠命令从「敲命令」降成「点一次」，同时不改变原有行为。

## 目标

- 输入框工具条右侧新增一个按钮，点一次就用 Visual Studio Code 打开当前工作目录。
- 斜杠命令 `/vscode` 与命令面板入口保留，行为、提示文案与按钮完全一致。
- 本版只做本地开发加载，不上架。

## 验收

- 有工作目录时：点按钮打开 VSCode，toast 提示「已用 VSCode 打开」。
- 没有工作目录时：两条入口都提示「当前没有工作目录，先打开一个项目。」，且都不拉起命令。
- 找不到可用命令时：提示「打不开 VSCode。请确认已安装 Visual Studio Code。」
- `/vscode` 仍可执行，命令 id、标题不变。
- 按钮不需要打开工作面板、不需要先敲斜杠；输入框可见时点一次即完成。
- 按钮期间重复点击不重复打开。

## 约束

- 只认一个按钮方法（`openWorkspace`），不接受的调用直接拒绝，不猜意图。
- 不新增网络、文件、剪贴板权限。
- 渲染器模块必须是无构建 ES 模块，不能用 JSX、不能依赖 npm 包（宿主只提供 `react`/`react-dom`）。
- 单次 `plugin.call` 宿主预算 2 秒，因此打开动作必须在拉起进程后立即返回。

## 不做

- 不改插件 id、命令 id、打开顺序（`open -a "Visual Studio Code"` → `code`）。
- 不再走独立窗口或工作面板标签页。
- 不为上架调整清单：本版带 `renderer` 字段，市场版本另行处理。
